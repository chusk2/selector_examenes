# Tipos de ejercicio

Nombres de tema unificados con `quimica_keywords.json` (minúsculas, sin tildes, `_` en vez de espacios).
Versión para leer con Python: `tipos_ejercicio.json`.

## Modelo 2024+ (`modelo_2024`)
- 2 problemas (3A / 3B + Competencial)
- 3 cuestiones teóricas (1A / 1B, 2A / 2B, 4B)

1A, 1B:
- configuracion_electronica
- propiedades_periodicas
- enlace_quimico

2A, 2B:
- equilibrio_quimico (Le Chatelier)
- cinetica
- acido_base
- redox (pilas galvánicas / electrolisis teórico)
- termoquimica (teoría)

3A, 3B:
- termoquimica
- solubilidad (problema)
- acido_base (problema)
- redox

4A: formulacion_organica

4B: reactividad_organica

5: competencial
- formulacion_inorganica
- Problema acido_base / redox / equilibrio_quimico / solubilidad
