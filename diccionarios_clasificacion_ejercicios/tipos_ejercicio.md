# Tipos de ejercicio:

## Modelo 2024+
- 2 problemas (3A / 3B + Competencial)
- 3 cuestiones teóricas (1A / 1B, 2A / 2B, 4B)

1A, 1B:
- Configuración electrónica
- Propiedades periódicas
- Enlace químico

2A, 2B:
- Equilibrio químico (Le Chatelier)
- Cinética
- Ácido base
- Redox (pilas galvánicas / electrolisis teórico)
- Termoquímica (teoría)

3A, 3B:
- Termoquímica
- Solubilidad (problema)
- Ácido base (problema)
- Redox

4A: formulación orgánica

4B: Reactividad orgánica

5: competencial
- formulación inorgánica
- Problema ácido base / redox / Equilibrio químico / solubilidad
